# Client photos

Put photos and videos from Aliya here, then ask Claude to use them on the website.

- **Full-size originals work best.** WhatsApp and Messenger shrink photos, so ask for them by AirDrop, email or Google Drive, or through WhatsApp's "Document" option.
- **Any file names are fine.** If a photo is meant for a particular section, you can put it in a subfolder named after it (for example `hero`, `services`, `work`, `live-events` or `learn`). You can also just say so when you ask.
- **Nothing here goes on the website by itself.** This folder isn't uploaded to Vercel. Photos that get used are copied into `src/assets/images/` (or videos into `public/video/`), and the originals here stay untouched.
