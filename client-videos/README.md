# Client videos

Put videos from Aliya here when they're meant for the website. Drag them in from Finder, or onto this folder in the
editor's file explorer. Photos go in `client-photos/`.

- **Full-size originals work best.** WhatsApp and Messenger shrink videos, so ask for them by AirDrop, email or Google Drive, or through WhatsApp's "Document" option.
- **Any file names are fine** (.mp4, .mov and so on). If a video is meant for a particular place, such as the hero film, just say so when you ask.
- **Nothing here goes on the website by itself.** This folder isn't uploaded to Vercel or GitHub. Videos that get used are edited into `public/video/`, and the originals here stay untouched.
